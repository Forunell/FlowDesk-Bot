# FlowDesk — фактическая проверка

Дата отчёта: **04.11.2026**, часовой пояс пользователя — Europe/Kiev. В приложении даты заявок и фильтры явно подписаны UTC.

Среда: Windows x64, локальный Python 3.13.12, Microsoft Edge в headless-режиме через Playwright 1.64.1. Проверенные библиотеки зафиксированы в `requirements-*-lock.txt`. Все данные тестов вымышлены.

**Итог: 41 pytest-тест пройден, Ruff пройден, браузерный сценарий пройден.** В браузере проверены три страницы при трёх ширинах: девять комбинаций. Зафиксированы ноль внешних запросов приложения и ноль ошибок JavaScript. Это не проверка настоящего Telegram и не аудит безопасности для публичного размещения.

## Выполненные команды

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\check.ps1 -Browser
.\.runtime\python\python.exe -m compileall -q flowdesk tests scripts
.\.runtime\python\python.exe -m pip check
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1 -Port 8000
```

Повторный `setup.ps1` завершился успешно на уже установленной среде. Первоначальная установка Python, pip и библиотек выполнена отдельными командами с официальных источников; весь путь установки скриптом на совершенно чистой Windows не проверялся.

Финальный `check.ps1 -Browser`: Ruff `All checks passed!`, pytest `41 passed, 1 warning`, затем браузерный `PASS`. Предупреждение Starlette относится к будущей замене `httpx` на `httpx2` в TestClient; текущие тесты выполняются успешно. Оно не скрыто. `compileall` — код выхода 0, `pip check` — `No broken requirements found`.

Команда `python -m flowdesk telegram` без токена корректно завершилась с кодом 1 и сообщением о необходимости локальной настройки; соединение с Telegram не устанавливалось.

При проверке `start.ps1` получен HTTP 200 от `/demo`, подтверждена загрузка локального CSS. `netstat` показал `127.0.0.1:8000 LISTENING`. Проверочный сервер остановлен после проверки; для открытия приложения запустите `scripts/start.ps1` снова.

## Найдено и исправлено

- В первом pytest-запуске отсутствовала родительская папка для заданного `--basetemp`: это ошибка подготовки тестового запуска. Итоговый скрипт создаёт `test-results`, а временными базами управляет pytest.
- На 360 px невидимый заголовок таблицы расширял документ из-за абсолютного позиционирования. Контейнер таблицы получил собственную область позиционирования; повторно пройдены все девять размеров/страниц.
- PowerShell 5.1 снимал кавычки во встроенной Python-команде настройки. Инициализация вынесена в отдельный `scripts/init_config.py`; проверена реальная команда `setup.ps1`.
- Уточнён поиск по отображаемому номеру `FD-0001`; добавлена проверка. Добавлен отзыв старых административных сессий при смене пароля.

На финальном прогоне FAIL нет. Неисполненные проверки отмечены NOT TESTED и не считаются пройденными.

## Пять ручных проверок для владельца

1. Создайте заявку в `/demo` с `demo@example.com`. Перед подтверждением измените имя. После подтверждения получите номер.
2. Начните следующую заявку и отмените. Затем повторите первую с теми же данными: новая запись не должна появиться.
3. Войдите в `/admin`, найдите номер, установите «У роботі», добавьте заметку; обновите страницу и убедитесь, что данные сохранились.
4. Отфильтруйте заявки и скачайте CSV. Выйдите из кабинета: прямой переход к `/admin/export.csv` должен вернуть страницу входа.
5. Добавьте тестовые примеры, откройте очистку, сначала откажитесь, затем подтвердите словом `ВИДАЛИТИ`. Перезапустите сервер и проверьте итоговый список.
